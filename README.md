# deasung.github.io — 대성게임즈 사이트

GitHub Pages(Jekyll)로 배포. 출시한 게임의 소개·개인정보처리방침을 이 사이트에서 관리한다.

## ⚠️ app-ads.txt — 지우거나 바꾸지 말 것
- 루트의 `app-ads.txt`는 **모든 앱이 같이 쓰는 파일**이다(AdMob 게시자 ID 하나).
- 지우거나, 이름·위치를 바꾸거나, 내용을 고치면 **모든 앱의 광고 수익이 함께 영향**을 받는다(AdMob이 광고 인증을 못 함).
- 사이트를 개편할 때도 그대로 둔다. 광고 네트워크를 추가할 때만 줄을 **덧붙인다**.
- 각 앱의 Play 스토어 「개발자 웹사이트」는 `https://deasung.github.io`여야 이 파일이 인식된다.

## 페이지 구조
- `/` 게임 목록, `/games/<게임>/` 게임 소개
- `/<게임>/` 국문 처리방침, `/<게임>/en` 영문 처리방침 (Play Console 개인정보처리방침 URL과 앱 안 링크를 이 주소로)

## 새 처리방침 페이지 front matter
머리 메뉴의 언어 전환 링크는 페이지마다 지정한다(지정 안 하면 「홈」만 나옴).
```yaml
---
layout: default
title: 도시락 블록 개인정보처리방침
lang: ko                      # 영문판은 en
lang_alt: /bento-block/en     # 반대 언어 페이지 주소(영문판에서는 /bento-block/)
---
```
- 새 앱을 추가하면 `_layouts/default.html` 바닥글의 처리방침 목록에도 넣는다.
- 처리방침을 개정하면 이전 버전을 `/<게임>/YYYY-MM-DD` 같은 주소로 남기고 12절에서 링크한다.
- 공개 저장소라 올리면 바로 공개된다. 초안은 여기에 올리지 않는다.
