# コンビニ陳列パズル プライバシーポリシー

金大成（以下「運営者」）は、大韓民国の個人情報保護法、日本の個人情報の保護に関する法律（以下「個人情報保護法」）その他の関係法令を遵守し、アプリ「コンビニ陳列パズル」（韓国語名「편의점 진열 정리」、以下「本アプリ」）の利用者の情報を以下のとおり取り扱います。本日本語版と韓国語版に相違がある場合は韓国語版が優先します。ただし、13. は日本国内の利用者に適用される事項として本日本語版の内容によります。

**施行日：2026年11月12日**

### 1. 本アプリが直接取得する情報
本アプリには会員登録・ログイン機能および決済（アプリ内課金）機能はなく、運営者は氏名・電話番号・メールアドレスなど利用者を直接識別できる情報を受け取りません。レベルの進行状況、レベルごとの星と手数の記録、プレイ中のレベルの手順と補助機能の残り回数、設定（効果音・バイブレーション・利用状況データの送信）、広告表示回数の記録、アプリのエラー・終了記録は**利用者の端末内にのみ保存**され、運営者には送信されません。これらはアプリの削除または端末設定でのアプリデータ削除により消去されます。Android のバックアップ機能をオンにしている場合、これらの情報が利用者ご本人の Google アカウントのバックアップに含まれることがあります。

### 2. 自動的に取得される情報と取得者
本アプリには Google LLC が提供する以下のツールが組み込まれており、本アプリの利用時に以下の情報が **Google により自動的に取得**されます。

| ツール | 取得される情報 | 目的 |
|---|---|---|
| Google AdMob（広告：バナー・全画面・リワード） | 広告 ID、App Set ID などの端末識別子、IP アドレス（おおよその位置の推定）、端末情報（機種・OS など）、広告の表示・クリック・リワード広告の視聴完了などの利用履歴、診断情報（起動時間・エラーなど） | 広告の表示、報酬付与の確認、広告効果の測定、不正クリックの防止 |
| Google Firebase Analytics（利用統計） | アプリインスタンス ID（インストールごとに生成されるランダムな番号）、ゲームの利用履歴（レベルの開始・クリア・やり直し・行き詰まりと、その時のレベル・手数・最少手数・星・所要時間・挑戦回数、元に戻す・ヒント・空き棚の使用有無、リワード広告の種類と視聴完了の有無、全画面広告の表示、初回起動・セッションなどの自動取得イベント）、端末情報（機種・OS・言語）、おおよその地域（IP アドレスから推定） | レベル難易度の調整などアプリの改善 |

- Firebase Analytics の情報は**広告のパーソナライズに使用せず**、Google 広告とリンクしておらず、Analytics による広告 ID の取得もオフにしています。
- Google による情報の取扱いは、[Google プライバシー ポリシー](https://policies.google.com/privacy?hl=ja)および[Google のサービスを使用するサイトやアプリから収集した情報の Google による使用](https://policies.google.com/technologies/partner-sites?hl=ja)でご確認いただけます。

### 3. 利用目的
上記の情報は、2. の表に記載した目的（広告の提供、リワード広告の報酬付与、アプリの利用統計の分析、不正利用の防止）にのみ利用します。

### 4. 取扱いの委託および外国への移転
運営者は、広告の提供と利用統計の分析のため、次のとおり情報の取扱いを委託しており、その過程で情報が国外に移転されます。

| 提供先 | Google LLC（米国）・連絡先：https://support.google.com/policies/contact/general_privacy_form |
|---|---|
| 移転先の国 | 米国その他 Google がデータセンターを運営する国 |
| 移転する項目 | 広告 ID、アプリインスタンス ID、IP アドレス、端末情報、アプリの利用履歴 |
| 移転の時期・方法 | 本アプリの利用時にネットワーク経由で送信 |

| 保存期間 | 6. と同じ |
| 拒否の方法と影響 | 7. の方法で拒否できます。利用統計をオフにしても本アプリの機能に制限はありません。広告 ID を削除すると、パーソナライズされていない広告が表示されます。 |

### 5. 第三者への提供
運営者は、2. および 4. に記載した場合を除き、利用者の情報を第三者に提供しません。

### 6. 保存期間と削除
- Firebase Analytics：取得日から **2 か月**保存した後、Google により自動的に削除されます。
- Google AdMob：Google のプライバシー ポリシーおよびデータ保持ポリシーによります。
- 端末内の情報：アプリの削除またはアプリデータの削除により直ちに削除されます。
- 運営者は、利用者の情報を保存するサーバーを運用していません。

### 7. パーソナライズ広告と利用統計の停止方法
- **利用統計をオフにする：** 本アプリの設定で「利用状況データを送信」（韓国語画面では「분석 정보 보내기」）をオフにすると、それ以降 Firebase Analytics の情報は送信されません（送信済みの情報は 6. の保存期間経過後に削除されます）。この設定は広告（AdMob）には適用されません。
- **パーソナライズ広告を停止する：** 端末の設定 > Google > 広告で「広告 ID を削除」（Android 12 以降）または「広告 ID をリセット」を選択できます。メニュー名は端末により異なる場合があります。広告 ID を削除しても広告は表示されますが、興味・関心に基づかない広告になります。Android 13 以降では、端末の広告プライバシー設定で広告トピックをオフにできます（メニュー名は端末により異なる場合があります）。
- **広告の同意を変更する：** 法令上同意が必要な地域（欧州経済領域など）では、本アプリの設定 > 「広告の同意を再設定」（韓国語画面では「광고 동의 다시 설정」）から広告に関する同意を変更できます。その他の地域ではこのメニューは選択できない状態で表示されます。
- リワード広告は、利用者がボタンを押して希望した場合にのみ表示されます。

本アプリは 13 歳未満のお子様を対象としていません。運営者はお子様の情報を直接取得しません。お子様の情報が取り扱われていることを知った保護者の方は、下記のお問い合わせ先までご連絡ください。削除など必要な対応をいたします。

### 9. 利用者の権利と行使方法
利用者は、ご自身の情報について開示・訂正・削除・利用停止等を求めることができます。ただし、本アプリにはアカウントがないため、運営者は特定の利用者の情報を識別・照会できません。7. の方法（利用統計のオフ、広告 ID の削除）および Google が提供する方法をご利用ください。その他のご請求は下記のお問い合わせ先までお送りください。誠実に対応いたします。

### 10. 安全管理のための措置
運営者は利用者の情報を保存するサーバーを運用しておらず、Google へ送信される情報は通信時に暗号化（TLS）されます。本アプリが求める権限はすべてインストール時に自動的に許可される通常の権限であり、位置情報・連絡先・写真・カメラ・マイク・ストレージなど、利用者の個別の許可が必要な権限はありません。本アプリが使用する権限は、インターネット接続とネットワーク状態の確認（INTERNET、ACCESS_NETWORK_STATE）、広告 ID と Android の広告機能（広告 ID・広告効果の測定・興味／関心のトピック：AD_ID、ACCESS_ADSERVICES_AD_ID・ATTRIBUTION・TOPICS）、広告・分析ツールが処理を終えるまで端末をスリープさせない権限（WAKE_LOCK、FOREGROUND_SERVICE）、インストール元の確認（Google Play のインストールリファラー、BIND_GET_INSTALL_REFERRER_SERVICE、Firebase Analytics が使用）、アプリ内部の通知を保護する権限（DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION）です。バイブレーションは端末のタッチフィードバック機能を使用し、別途の権限は使用しません。
